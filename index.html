Selling Inventory Adapter — Privacy Policy

Effective November 17, 2026

Selling Inventory Adapter is a privately operated tool being developed for its operator's own eBay seller account. It is not currently a service offered to other eBay users.

Information processed today

The application currently receives eBay Marketplace Account Deletion notifications. These messages may contain eBay user identifiers and event metadata. The notification endpoint validates the notification's cryptographic signature, checks the message, and acknowledges it when processing succeeds. This application currently maintains no separate database of eBay buyer or seller personal records and does not persist the notification body as an application record.

Credentials and authorization

Application credentials and verification settings are held as restricted configuration secrets. A short-lived eBay application access token may be cached in memory for communication with eBay. The application does not request an eBay account password. Seller-authorized listing features and associated OAuth token storage are not yet active; this policy will be reviewed before those features are enabled.

Data use and disclosures

Notification information is used only to authenticate and respond to eBay's account-deletion events. The application does not sell personal information or use notification data for advertising or profiling. eBay supplies the notifications, and Cloudflare provides the hosting infrastructure. Those services may process technical connection data needed to deliver requests and operate the service.

Retention and deletion

Notification data is processed transiently and is not retained in an application-managed user record. Application diagnostic messages are designed to omit notification bodies, eBay user IDs, access tokens, and signature values. If future versions retain personal data, deletion handling and this policy must be updated before those features are activated.

Seller controls and updates

When seller authorization is added, the seller will be able to revoke application access through their eBay account. This policy may be updated as the application's features change; the effective date above will be revised accordingly.

Privacy inquiries

This application is currently used solely by its operator. Privacy questions or requests can be directed to that operator through the contact channel used to provide access to the application. A public contact method will be added before the application is made available to other users.
